Features

Everything you need to manage cron

Stop fighting with crontab syntax. Cron Manager gives you a modern GUI with safety features that the command line can't.

+

Full CRUD Operations

Create, edit, enable/disable, and delete cron jobs through a clean interface. Search and filter by keyword, tag, or status.

☷

Visual Expression Builder

Build cron schedules visually with dropdowns and sliders, or type raw expressions. See next N execution times before saving.

✓

Conflict Detection

SHA-256 checksums detect external crontab changes before overwriting. Never accidentally lose edits made outside the app.

↺

Automatic Backups

Every save creates a timestamped backup with 0600 permissions. 20-file retention policy with one-click restore.

⇄

Lossless Round-Trips

Comments, whitespace, environment variables, and % in commands are preserved verbatim. What you load is what you save.

⌨

Keyboard Shortcuts

Power-user friendly with full keyboard navigation. Undo/redo for in-session edits. Tag system for job organization.

Get Started

Install in seconds

Build from source with Cargo. Requires Rust 1.70+ and a system with crontab (Linux, macOS).

# Clone the repository
git clone https://github.com/omar16100/cron_manager.git
cd cron_manager

# Build release binary
cargo build --release

# Run
./target/release/cron_manager
